The Consensus of Contrarians

Do nine frontier models from eight labs collapse to the same “contrarian” opinions? A 1,521-generation pilot, run end to end, to decide whether the full study is worth building.

Primary hypothesis not supported

The models are distinguishable. “Five labs, one generator” fails this pilot.

Against a permutation null in which every model is a draw from one shared generator, each model is significantly more self-similar than chance — within-minus-between similarity gap versus a null of (, p < 0.002, the resolution floor at 500 permutations). It replicates in both embedding spaces. The labs have detectable house styles.

But the effect is small in absolute terms, and the study's most quotable sub-result survives intact: told explicitly to produce an opinion no other AI would give, the models moved apart. They cannot diverge on command.

The test

Permutation null — are the models separable at all?

This is the load-bearing test, and the reason raw divergence numbers cannot be read directly at pilot scale. With ~55 claims per model spread across a few hundred clusters, two identical generators would still produce near-disjoint distributions. So each statistic is compared against its own distribution under shuffled model labels — the literal “one generator” hypothesis.

Robustness

Does the result survive the choices we made?

Two places this study could have fooled itself: the clustering algorithm and the embedding model. (A temperature sweep was run and then dropped — the effect was small, monotonic and not separable from noise at this sample size.)

Clustering method changes the absolute Hill number by up to ~30% but not the ordering or the sign of any conclusion. The primary method — agglomerative at a cosine threshold calibrated against LLM-judge pairwise adjudication rather than chosen by hand — is the one with an external referent for its single free parameter.

Method

How the pilot was run

Nine models, one flagship per lab plus a within-lab scale contrast, all reached through a single OpenRouter key so that wire format and sampling parameters are identical across labs. Fresh context per call, no system prompt beyond the shared format line, top_p 0.95.

One deliberate deviation from the design. The design specified max_tokens 200–500. Every current flagship is a reasoning model that draws chain-of-thought from the same budget: measured at 500, Claude and Gemini truncated mid-sentence and Kimi and GLM returned no answer at all, only raw reasoning. Disabling reasoning would have been the cleaner match to intent, but Gemini and Grok reject it outright and Qwen returns an empty completion — a setting available on 7 of 9 models would confound lab with sampling regime. reasoning.effort=low at a 1200-token ceiling is the one configuration all nine accept. 32 rows that still truncated were re-drawn at a raised cap and flagged in the dataset rather than dropped, since truncation correlates with longer reasoning and dropping them would have biased the result toward the thesis.

Answers were reduced to one canonical claim sentence by a judge model under a fixed rubric, with refusals and hedges coded rather than discarded. Claims were embedded in two independent spaces, then clustered once over the pooled set so cluster labels are shared and cross-model divergence is defined. The “same opinion” cosine threshold was fitted to 292 LLM-adjudicated claim pairs, stratified across the similarity range.
